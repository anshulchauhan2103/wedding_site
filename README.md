# kishuandanshul.com — Save the Date 💍

Save-the-date website for Kishika & Anshul's wedding — **27–28 January 2027, Chandigarh**.

Hosted on GitHub Pages at [kishuandanshul.com](https://kishuandanshul.com).

## Editing

| What | Where |
|---|---|
| Names, dates, city, message | `index.html` |
| Colors, fonts, layout | `style.css` |
| Countdown target date | `script.js` (`WEDDING` constant) |
| Background photo | `bg.jpg` (desktop) / `bg-mobile.jpg` (phones) |
| WhatsApp link-preview card | `og-image.png` |

Push to `main` and GitHub Pages redeploys automatically in about a minute.

## Preview locally

```bash
python3 -m http.server 8642
# open http://localhost:8642
```
